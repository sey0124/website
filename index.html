4. Canva에서 웹사이트 만드는 순서

실제 Canva 메뉴는 계정과 버전에 따라 조금 다를 수 있습니다. 아래 순서는 12차시 수업에서 따라 하는 기본 작업 순서입니다.

① Canva 로그인www.canva.com 접속
② 웹사이트 템플릿템플릿 검색에서 ‘웹사이트’ 선택
③ 디자인 이름 변경12차시_내브랜드_웹사이트
④ 섹션 구성HOME·PRODUCT·CONTACT 우선
⑤ 이미지 업로드업로드 → 파일 업로드
⑥ 브랜드 글쓰기AI가 작성한 문구 붙여넣기
⑦ 상품·결과물이미지·카드뉴스·상세페이지 배치
⑧ 홍보 영상MP4를 업로드하여 배치
⑨ 버튼·링크버튼 선택 후 실제 URL 연결
⑩ 화면 점검PC·모바일 미리보기
⑪ 사이트 게시게시·주소·공개 설정 확인
⑫ 주소 복사다른 기기에서 직접 열어 확인
제작 중 링크·파일을 추가할 때는 실제 존재하는 정보만 사용하고, 사업용 이미지·영상·음원의 사용 권한을 확인하세요.
